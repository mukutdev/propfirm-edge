DESIGN DETAILS & INTERACTIONS

- Smooth scroll behavior throughout

- Fade-in-up animation on all sections as they enter viewport

- Gradient text on all major headlines (purple to pink)

- All CTA buttons: pill shape, gradient background, subtle glow shadow 

  on hover matching the gradient colors

- Card hover: lift + purple glow border effect

- Scrolling ticker: smooth infinite loop, no stutter

- No stock photos — use abstract trading chart line graphics or 

  geometric shapes as decorative elements only

- Overall feel: Bloomberg Terminal meets modern SaaS landing page

- Mobile nav: full screen dark overlay menu

- Ticker, stats bar and comparison table scroll horizontally on mobile
